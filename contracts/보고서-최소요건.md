# 팀원 보고서 최소 요건

> C(기업 판정) 담당과 보고서를 쓰는 모든 사람에게.
> **목표주가는 필요 없습니다.** 아래 두 줄만 있으면 데스크가 나머지를 만듭니다.

---

## 반드시 필요한 것 — 두 줄

```
1. 이 주장이 맞으면 영업이익이 몇 % 변하는가
2. 그 계산 근거 — 어느 세그먼트가 × 얼마나 변하는가
```

**예시**

```
검사 부문이 영업이익의 88% (2025 사업보고서 II.사업의 내용 p.10)
물량 30% 증가 가정
→ 임팩트 +26%
```

이것만 있으면 데스크가 이렇게 계산합니다.

```
우리 TP  = 컨센 TP × (1 + 임팩트%)      ← 컨센 TP는 FnGuide에서 가져옴
델타     = 임팩트%
업사이드  = 우리 TP / 현재가 − 1
기대수익  = 업사이드 × 승률
```

**목표주가·PER·DCF·멀티플 전부 불필요합니다.**

---

## 없어도 되는 것

- 목표주가
- 밸류에이션 모델
- 재무제표 추정
- 정해진 서식 (서사형으로 써도 됩니다)

---

## 있으면 좋은 것

| 항목 | 없을 때 어떻게 되나 |
|---|---|
| **영업이익 1위 세그먼트 비중** | M1(AI 잠식) 판정이 보류되어 L3 중립 처리 → **☠ 함정을 놓칩니다** |
| **DART 원문 인용** | 그 사실이 무효화되어 의존하는 논리 고리가 끊김 1개로 계산됩니다 |
| **인과 사슬을 화살표로 명시** | 심사기가 대신 분해합니다. 다만 분해 결과가 의도와 다를 수 있습니다 |

---

## 심사에서 자주 죽는 패턴

```
✕  근거가 뉴스 기사       → 그 사실 무효화
✕  "업계 통념상 ~다"      → 전제 위치의 금지어. 무효화
✕  "AI 온다 → 우리 좋다"  → 비약. 중간 단계를 써야 합니다
✕  임팩트 숫자만 있고 산식 없음  → 무효. "+35%"는 아무나 쓸 수 있습니다
```

**반대로, 미래에 대해서는 자유롭게 쓰셔도 됩니다.**

```
○  "10~20년 뒤 이 구조는 오히려 강화될 가능성이 있다"
   → 결론 영역. 감점하지 않습니다.
```

우리 데스크 호흡은 10~20년입니다. **확정할 수 없는 미래를 확정하라고 요구하지 않습니다.**
다만 **지금 공시를 열면 확인되는 것**은 반드시 확인해서 써주세요.
