# desk-run

> **PLUS FUTURE AI ANTI PLATFORM PB팀 · 오케스트레이터**

파이프라인을 순서대로 돌린다. **스킬이 아직 없어도 멈추지 않고, 어디까지 갔는지 남긴다.**

계약은 `contracts/pipeline.md`가 정본이다. 이 파일과 어긋나면 계약 파일을 따른다.

---

## 0. 핵심 규칙 — 스킬을 직접 부르지 않는다

```
각 단계는 앞 파일을 읽고 다음 파일을 쓴다.
스킬끼리 직접 호출하지 않는다.
```

4명이 각자 브랜치에서 만드는 중이라 **누가 언제 올라올지 모른다.**
직접 호출 구조면 한 명만 늦어도 전체가 멈춘다. 파일로 주고받으면 안 멈춘다.

---

## 1. 실행 절차

### 1-1. run_id 결정

```
run_id = YYYY-MM-DD_<산업명>       예: 2026-08-13_농업
폴더    = runs/<run_id>/
```

폴더가 이미 있으면 **이어서 진행한다.** 처음부터 다시 돌리지 않는다.

### 1-2. 단계별 처리 — 각 단계에 같은 규칙을 적용한다

```
① 산출 파일이 이미 있는가?
     있다  →  계약 검증만 하고 다음 단계로 (재실행 안 함)
     없다  →  ②로

② 담당 스킬이 저장소에 있는가?
     있다  →  그 스킬을 실행하고 산출 파일을 쓴다
     없다  →  ③으로

③ 수동 입력 안내를 출력하고 정지한다
     - 만들어야 할 파일 경로
     - contracts/pipeline.md 의 해당 절
     - 최소 필수 필드 목록
     - 예시 JSON
```

**③에서 임의로 파일을 지어내지 않는다.** 없는 데이터를 채우면 뒤에서 조용히 틀린 값이 나온다.

### 1-3. 단계 표

| 순서 | 산출 파일 | 담당 스킬 | 담당 |
|---|---|---|---|
| 1 | `01-industry.json` | `industry-screen` | B |
| 2 | `02-companies.json` | `company-screen` | C |
| 3 | `03-valuation.json` | `core/` (Python) | A |
| 4 | `04-tackle.json` | **`pro_tackler`** | D |
| 5 | `report.md` | (팀장 수기 또는 `core/report.py`) | 팀장 |

## 2. 단계별 상세

### 1단계 · 산업 스크린 → `01-industry.json`

사용자가 산업을 **지정했으면** `mode: "verify"`, **추천을 요청했으면** `mode: "discover"`.

```
게이트:  consensus_universe_count < 5   →  gate REJECT, 정지
        gate == "REJECT"               →  사유를 사용자에게 전달하고 정지
```

`peers`(동종 3사)를 반드시 채운다. **4단계 M3 판정의 입력**이며,
**심사 대상 자신은 제외**해야 한다. 자기가 자기 비교군에 들어가면 마진 격차가
자동으로 축소되어 판정이 오염된다.

### 2단계 · 기업 판정 → `02-companies.json`

**두 형식을 모두 받는다.**

```
구조화형   answers(Q1~Q5) + evidence
서사형     report_md 경로만
둘 다      가장 좋다
```

서사형만 와도 4단계가 처리한다 — `pro_tackler`가 문장을 [사실]/[연결]/[전망]으로
태깅해서 심사한다. **형식을 강제해서 팀원을 막지 않는다.**

`segment_top`(영업이익 1위 세그먼트)을 꼭 채운다. 없으면 4단계 M1이 보류되어
L3(중립)로 처리되고, **☠ 함정을 놓친다.**

### 3단계 · 조정률 산출 → `03-valuation.json`

`core/` 가 아직 없으면 **여기서 정지하는 게 정상이다.** 억지로 넘기지 않는다.

다만 아래 두 경우는 예외적으로 진행한다.

```
컨센 TP를 못 구했다      →  flags 에 "컨센 미확보" 넣고 진행
                            (4단계 컨센 게이트는 건너뛴다)
임팩트 규모가 없다        →  flags 에 "규모 미기재" 넣고 진행
                            (승률에서 감점)
```

**데이터가 없다는 이유로 종목을 죽이지 않는다.** 다만 리포트에 반드시 표기한다.

### 4단계 · 태클 심사 → `04-tackle.json`

`pro_tackler` 스킬을 실행한다. 입력은 `01`·`02`·`03` 세 파일이다.

```
02 만 있어도 돌아간다      서사형 보고서 심사
01 이 있으면 M2·M3 정확도가 올라간다   산업 성장 · 동종 3사
03 이 있으면 컨센 게이트가 돈다        |델타| < 20%p 탈락
```

`picks` 가 0개면 `rejection_notice` 를 채운다. 1개 이상이면 채우지 않는다.

### 5단계 · 리포트 → `report.md`

`04-tackle.json` 의 `table` 을 심사표로 그대로 붙이고,
팀장 항목(배분 비중 · 금액 기대수익 · 청산 규칙 · 고객 유형)을 채운다.

**"유망합니다"로 끝내지 않는다. 금액으로 끝낸다.**

## 3. 진행 상황 출력

매 단계마다 아래를 출력한다. 어디까지 갔는지가 항상 보여야 한다.

```
run: 2026-08-13_농업

  [1] 산업 스크린    ✓ 01-industry.json      (기존 파일 사용)
  [2] 기업 판정      ✓ 02-companies.json     company-screen 실행
  [3] 조정률 산출    ⏸ 03-valuation.json     core/ 미구현 — 수동 입력 필요
  [4] 태클 심사      ·
  [5] 리포트         ·

→ runs/2026-08-13_농업/03-valuation.json 을 만들어 주세요.
  필수: ticker, adjust_rate, consensus_tp, price, coverage_count
  참고: contracts/pipeline.md §03-valuation.json
```

기호: `✓` 완료 · `⏸` 대기(수동 입력 필요) · `✕` 게이트 탈락 · `·` 미도달

---

## 4. 부분 실행

특정 단계만 돌릴 수 있어야 한다.

```
desk-run 농업                  전체 (기존 파일은 건너뜀)
desk-run 농업 --from 4         4단계부터 (앞 파일이 이미 있을 때)
desk-run 농업 --only 4         4단계만 다시
desk-run --reports <경로>      01~03 없이 보고서만 넣고 4단계 직행
```

마지막 형태가 **오늘 실제로 쓰인 경로**다. 두산에너빌리티 보고서 하나만 가지고
`pro_tackler`를 돌렸다. **앞 단계가 하나도 없어도 심사는 된다.**

---

## 5. 계약 위반 처리

```
필수 필드 누락           →  어느 파일 어느 필드인지 지목하고 정지
gate REJECT             →  정지. 사유 전달
picks 0개               →  rejection_notice 작성 후 정지
consensus_tp 전부 없음   →  경고 후 진행, report.md 에 "델타 미산출" 명시
```

**억지로 진행하지 않는다.** 뒤에서 조용히 틀린 값이 나오는 것보다 멈추는 게 낫다.

---

## 6. 하지 말 것

| 금지 | 이유 |
|---|---|
| **없는 데이터를 지어내기** | 뒤에서 조용히 틀린 값이 나온다 |
| **스킬을 직접 호출하는 구조로 바꾸기** | 한 명만 늦어도 전체가 멈춘다 |
| **이미 있는 산출 파일을 덮어쓰기** | `--only` 로 명시했을 때만 재실행 |
| **계약에 없는 필드를 임의로 추가** | 다음 단계가 읽지 못한다. 계약 파일을 먼저 고쳐라 |
| **게이트 탈락을 무시하고 진행** | 게이트가 장식이 된다 |

---

## 7. A 담당에게

이 스킬은 **`core/run.py` 를 대체하지 않는다.** 파일 계약과 진행 순서만 정의한 껍데기다.

3단계에서 실제 계산은 A의 Python이 한다.

```
core/adjust.py     조정률 · TP · 델타
core/select.py     하드컷 · 정렬 · 분산
core/macro.py      FRED 게이트
core/report.py     리포트 렌더
```

`core/` 가 올라오면 이 스킬의 3단계가 그것을 부르도록 한 줄만 바꾸면 된다.
**계약 파일(`contracts/pipeline.md`)의 JSON 스키마만 지켜 주면 앞뒤가 안 바뀐다.**
