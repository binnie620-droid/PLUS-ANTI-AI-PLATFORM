# Quality-Control Checklist

보고서를 **확정하기 직전** 반드시 이 체크리스트를 통과한다. 하나라도 미충족이면 확정하지
말고 해당 부분을 보완한 뒤 재검사한다. `output-schema.md`의 `quality_gate_passed`는 이
체크리스트를 전부 통과했을 때만 `true`로 표시한다.

## CASE A / B / C 체크리스트 (기업이 있을 때, 15개 항목)

- [ ] AI와 산업의 연결이 단순 Narrative에 그치지 않았는가? (계약/공시로 뒷받침되는가)
- [ ] 산업 성장 → 기업 Revenue 연결이 증명되었는가?
- [ ] Revenue → Earnings 연결이 설명되었는가? (매출은 늘어도 마진이 무너지는 경우는
      없는가)
- [ ] Earnings → Valuation 연결이 설명되었는가?
- [ ] 현재 주가가 반영하고 있는 기대 수준을 고려했는가? (Independent Review 질문 4)
- [ ] 목표주가 산식이 재현 가능한가? (계산식이 리포트에 명시적으로 드러나는가)
- [ ] Target Multiple의 근거가 있는가? (임의 입력이 아닌가)
- [ ] 투자기간(Investment Horizon)이 Catalyst와 연결되어 있는가?
- [ ] Bull/Base/Bear가 숫자로 검증되었는가? (정성적 서술만 있고 숫자가 없는 경우 실패)
- [ ] 핵심 숫자마다 출처가 있는가?
- [ ] Fact와 Assumption을 구분했는가? ([FACT]/[ESTIMATE]/[ASSUMPTION] 태그)
- [ ] 반대 논리를 충분히 검토했는가? (Independent Review 10문항 전부 답했는가)
- [ ] 투자하지 않는 것이 더 나은 선택인지 검토했는가? (자동 BUY로 흐르지 않았는가)
- [ ] 2~3개 기업일 경우 상대적인 투자매력도를 비교했는가?
- [ ] 최종 Top Pick/1위 선정 이유가 명확한가?

## 산업 무관성 체크 (CASE A/B/C, 12개 항목)

**참조 구현이 전력기기라서 그 업종의 내용이 남는 사고가 반복된다.** 발행 전 전수 확인한다.

- [ ] 본문에 **다른 업종의 종목명·수치·업종명**이 남아 있지 않은가?
      (`940억원` `6,976원` `40.0배` `산일전기` `데이터센터` 등 전수 검색)
- [ ] **I장 1절이 Industry Economics**이며, 10개 질문에 이 산업의 답이 채워졌는가?
- [ ] **KPI가 Industry Economics에서 도출**되었는가? (참조 구현의 `수주·수주잔고·판가`를
      그대로 쓰지 않았는가)
- [ ] "이 지표는 이 산업에 한정된다"는 취지가 본문에 명시되고, **타 업종 대비 예시**가
      2~3개 제시되었는가?
- [ ] **AI 전달 경로 7종**을 각각 판정하고 근거를 붙였는가?
      (`AI→데이터센터→전력수요` 하나로 갈음하지 않았는가)
- [ ] **④ 제품 대체 위험(AI Disruption Risk)**을 명시적으로 판정했는가?
- [ ] **AI Materiality를 1~5로 판정**했고, 낮게 나왔으면 낮은 대로 서술했는가?
      (Materiality 3 이하인데 AI를 유일한 투자 논리로 세우지 않았는가)
- [ ] AI 영향을 **Near / Medium / Long으로 분리**하고, 목표주가에 **Near만 반영**했는가?
- [ ] AI 발전 시나리오 **A/B/C를 검토**했고, 그 결과를 **목표주가에 숫자로 반영하지
      않았음**을 명시했는가?
- [ ] **Investment Point 1이 AI인 경우**, AI 없이는 성립하지 않는 논리인지 확인했는가?
      (AI 없이도 성립하는 근거가 있으면 그것이 IP1이다)
- [ ] **V장 (1)에 Valuation Method 선택 근거**가 있는가? (채택 이유 + 배제한 방식의 이유)
- [ ] **Top Pick 비교가 공통 투자기준 12항목**인가? AI 노출과 AI 잠식 위험이 분리되었는가?

## 데이터 완결성 체크 (CASE A/B/C)

- [ ] **ROE·ROIC가 채워졌는가?** `확인 불가`로 비워두지 않았는가
      (`python tools/fetch_roic.py <ticker>` — DART로 계산되는 값이다)
- [ ] ROE·ROIC가 **최소 2개년**으로 방향을 보이는가?
- [ ] ROIC 변동을 **분자(NOPAT)와 분모(투하자본)로 나눠** 해석했는가?
      (증설로 분모가 커진 하락과 이익이 줄어든 하락은 다르다)
- [ ] **ROIC가 자본비용을 상회하는지** 한 문장으로 판정했는가?
- [ ] 계산 불가 항목(적자·지주·금융)은 사유를 밝히고 **대체 지표**를 썼는가?
      (지어낸 숫자가 없는가)
- [ ] **표지에 Long-Term Lens 비교표를 넣지 않았는가?** (표지는 Rating·TP·상승여력까지)

## CASE D 체크리스트 (0개 통과, 축소된 7개 항목 — 기업 관련 항목은 해당 없음)

- [ ] Skill 3의 반려지시서(또는 재구성한 탈락 근거)를 실제로 반영했는가?
- [ ] 산업 성장 논리에 출처가 있는가? (TAM/CAGR/수요 Driver)
- [ ] Fact와 Assumption을 구분했는가?
- [ ] "왜 지금 투자하지 않는가"에 대한 논리가 valuation/risk-reward 관점에서 구체적인가
      (단순히 "리스크가 있다"가 아니라 무엇이 부족한지)
- [ ] Monitoring Indicator와 재검토 Trigger가 관측 가능한 구체적 조건인가?
- [ ] **개별 기업 목표주가·등급이 리포트 어디에도 등장하지 않는가?** (등장하면 CASE D
      규칙 위반 — 즉시 삭제)
- [ ] Final Decision이 "NO INVESTMENT"이며 이를 적극적 판단으로 서술했는가?
