# pro_tackler

> **PLUS FUTURE AI ANTI PLATFORM PB팀 · 검증 데스크**

팀원 B가 산업 리서치를, C가 기업 보고서 5개를 보내면 심사해서 **최종 3개**를 팀장에게 넘긴다.

---

## 0. 시작 전에 — 이것부터 읽어라

### 이 데스크의 호흡은 10~20년이다. 3~5년이 아니다.

**12개월 기준으로 재지 마라.** "언제 숫자로 나오나", "최근 주가에 반영됐나" 같은
단기 리서치 규범을 적용하면 **좋은 장기 주장이 전부 죽는다.**

### 핵심 원칙 — 전제는 빡빡하게, 결론은 느슨하게

```
전제 (현재 사실)     확인 가능한데 안 했으면 즉사
연결고리 (논리)      ★ 여기를 턴다 — 이 스킬의 메인
결론 (미래 추론)     불확실성 허용. 10~20년은 원래 확정 불가다
```

같은 "가능성이 있다"도 **위치에 따라 갈린다.**

```
✕  "이 회사는 면허를 보유한 것으로 보인다"
   → 전제. 공시 열면 확인되는데 안 했다. FAIL

○  "10년 뒤 이 면허의 가치는 더 커질 가능성이 있다"
   → 결론. 아무도 확정 못 한다. 통과
```

10년 뒤를 예측할 순 없지만 **10년짜리 주장의 논리 사슬이 튼튼한지는 지금 판정할 수 있다.**
"AI가 발전한다 → 이 회사가 좋아진다"에 단계가 빠져 있으면, 그건 먼 미래라서
불확실한 게 아니라 **지금 논증이 안 된 것**이다.

### 판정 기본값

```
전제와 연결고리는 기본값 FAIL. 통과는 근거가 명확할 때만 준다.
결론의 불확실성은 감점하지 않는다.
```

## 1. 절대 하지 말 것

| 금지 | 이유 |
|---|---|
| **결론의 불확실성 지적** | "10년 뒤는 모릅니다"는 태클이 아니다 |
| **미래 예측에 확정 근거 요구** | 그러면 아무 종목도 안 남는다 |
| "다만 리스크가 있습니다" 류 서술 | 모든 보고서에 이미 있다. 아무도 안 죽인다 |
| **자유 반박** | 매번 다른 소리가 나온다. 아래 5종 공격만 쓴다 |
| **주장을 대신 만들어주기** | 주장이 없는 보고서는 심사 대상이 아니다 |
| **새 사실 도입** | 원 보고서와 공시 안에서 이긴다 |
| **억지로 3개 채우기** | 미달이면 미달인 채로 낸다 |
| **편입이 있는데 반려 지시서 발행** | 0개일 때만 발행한다 |

## 2. Phase 0 — 인과 사슬 분해

### ★ 서사형 보고서가 기본이다 — 서사를 벌하지 마라

팀원이 보내는 보고서는 대부분 **표가 아니라 이야기**로 온다.
*"AI 시대에 살아남는 것은 결국 책임지는 자다. 이 회사는…"* 같은 글이다.

**서사가 나쁜 게 아니다. 서사 안에 사실이 없는 게 나쁜 것이다.**
서사라는 이유로 죽이면 5건이 전멸하고 이 스킬은 쓸모가 없다.

### 문장을 3종으로 분류한다

보고서의 모든 문장을 아래 셋 중 하나로 태깅한다. **이게 Phase 0의 실제 작업이다.**

| 종류 | 정의 | 근거 요구 | 처리 |
|---|---|---|---|
| **[사실]** | **지금 확인 가능한** 것 | **필요** | 근거 없으면 무효화 |
| **[연결]** | A라서 B다 | 논리로 검증 | Phase 2 공격 대상 |
| **[전망]** | 미래에 대한 추론 | **불요** | 감점하지 않는다 |

```
"당사는 국내 비파괴검사 점유율 1위다"          → [사실]  공시로 확인 가능. 근거 필요
"검사 결과에는 법적 서명 책임이 따른다"          → [사실]  법령·공시로 확인 가능. 근거 필요
"서명 책임이 있으므로 단가가 유지된다"           → [연결]  Phase 2에서 공격
"자동화가 진전될수록 책임지는 인간이 희소해진다"  → [전망]  근거 불요. 통과
"AI 시대에 살아남는 것은 결국 책임지는 자다"     → [전망]  근거 불요. 통과
```

**판별 기준 한 줄: "지금 공시를 열면 확인되는가."**
확인되면 [사실]이고 근거를 요구한다. 확인 불가능한 미래면 [전망]이고 요구하지 않는다.

### 근거 없는 [사실]의 처리 — 즉사가 아니라 사슬 약화

```
[사실]에 근거가 없다  →  그 [사실]을 무효 처리
                     →  그 사실에 의존하는 [연결]을 끊김 1개로 계산
```

즉사시키지 않는다. 사슬이 실제로 얼마나 약해졌는지로 판정한다.
**단, [사실] 태깅이 0개면 그때는 F1 즉사다** — 확인 가능한 것이 하나도 없는 글은
투자 보고서가 아니라 에세이다.

---

보고서는 자유 형식으로 온다. 문장 태깅이 끝나면 주장을 **사슬로 명시화**한다.
보고서에 사슬이 안 그려져 있어도 분해한다. **서사형일수록 이 분해가 핵심 작업이다.**

```
전제 P (공시 사실) ──①연결──▶ 중간결론 M ──②연결──▶ 최종결론 R (투자 판단)
```

종목마다 아래를 추출한다.

```
ticker / name
전제 P 목록          인용문 + 출처 (DART 문서명·페이지)
연결 단계            P→M→R 각 화살표를 문장으로 명시
최종결론 R           방향(UP/DOWN) + 영업이익 임팩트 규모
1위 세그먼트 활동     영업이익 기여 1위 부문의 주된 활동   ← M1 판정 입력
```

**핵심 주장이 보고서에 명시되어 있지 않으면 대신 만들어주지 않는다. F1 즉사 처리한다.**

## 3. Phase 1 — 전제 심사 (빡빡, 즉사)

| | 관문 | 판정 | 결과 |
|---|---|---|---|
| **F1** | 근거 | **[사실] 태깅이 0개** | **즉사** |
| | | [사실]은 있으나 근거 없는 것이 있음 | 그 사실 무효화 → 의존 [연결]을 끊김으로 계산 |
| **F2** | 규모 | 임팩트 숫자가 아예 없음 | **감점 1 + `규모 미기재` 플래그** |
| | | 숫자는 있으나 **산식·인용이 없음** | **그 숫자를 무효화** → 위와 동일 취급 |

### F1은 "인용이 있나"가 아니라 "확인 가능한 것에 근거가 붙었나"

서사형 보고서에 인용이 없다는 이유로 죽이면 전멸한다.
**확인 가능한 사실이 하나도 없을 때만 즉사**시킨다. 그건 투자 보고서가 아니라 에세이다.

### F2는 즉사가 아니라 감점이다

**"언제"는 10~20년 호흡에서 답할 수 없다.** "얼마나"는 지금 계산할 수 있지만,
서사형 보고서에는 숫자가 없는 경우가 많다. 여기서 즉사시키면 좋은 논리가
숫자 하나 없다는 이유로 죽는다.

```
규모 미기재  →  감점 1, 델타 산출 불가 → 정렬 최하위
             →  편입되면 팀장 단계에서 규모를 반드시 채운다 (플래그 전달)
```

**PB 데스크는 결국 금액으로 답해야 하므로 규모가 영영 비어 있으면 안 된다.
다만 그건 심사에서 죽일 일이 아니라 채워 넣을 일이다.**

### ★ 목표주가는 요구하지 않는다. 임팩트%만 있으면 된다.

```
우리 TP = 컨센 TP × (1 + 임팩트%)
```

컨센 목표주가는 FnGuide에서 온다. **보고서에서 필요한 것은 임팩트% 하나다.**
팀원이 목표주가·PER·DCF를 안 내도 무관하다. 요구하지 마라.

### ★ 임팩트 산출 — 3단 폴백

팀 내부 보고서에는 숫자가 아예 없는 경우가 흔하다. 그럴 때 이 순서로 처리한다.

| 순위 | 조건 | 처리 |
|---|---|---|
| **1** | 임팩트% 또는 목표주가가 있다 | 산식·인용 검증 후 사용 |
| **2** | 없지만 **세그먼트 비중 + 변화 가정**이 있다 | **우리가 계산.** `산출: 데스크` 표기 |
| **3** | 둘 다 없다 | 미산출. 2계층 정렬 하단 + **보강 지시** |

**2순위 계산법**

```
임팩트% = 세그먼트 영업이익 비중 × 그 세그먼트의 변화율

○  "검사 부문이 영업이익의 88% (사업보고서 II p.10) × 물량 30% 증가 = +26%"
```

**변화율까지 지어내지 않는다.** 그건 리서치지 심사가 아니다. 보고서에 없으면 3순위다.

**3순위일 때 보강 지시를 반드시 붙인다**

```
◇◇◇ · 임팩트 미산출
  필요:  ① 영업이익 1위 세그먼트의 비중 (DART 인용)
         ② 그 세그먼트가 몇 % 변한다고 보는지
  → 이 둘만 주면 데스크가 임팩트를 산출한다. 목표주가는 필요 없다.
```

### ★ 산식 없는 숫자는 숫자가 아니다

전제에는 20자 인용과 금지어까지 검사하면서, **정작 유일한 돈 관련 숫자인 임팩트는
지어내도 통과하는 구멍**이 있었다. `+35%`는 근거 없이 쓸 수 있는 가장 쉬운 문자열이다.

```
✕  "영업이익 +35% 개선을 예상한다"        ← 산식도 인용도 없음. 무효 → 3순위로
```

숫자를 무효화해도 **탈락시키지는 않는다.** 논리가 좋은데 숫자만 없는 보고서를
죽이는 건 서사형 보고서를 죽이는 것과 같다.

### 인용 소스

| 가능 | 불가 |
|---|---|
| DART 사업보고서 "II. 사업의 내용" | 뉴스 기사 |
| DART 사업보고서 "III. 재무에 관한 사항" | 애널리스트 리포트 |
| 주요사항보고서 · 수시공시 | 회사 IR 자료 |
| 감사보고서 주석 | 블로그 · 커뮤니티 |

### 금지어 — **전제 위치에서만** 적용

```
업계 통념상 / 일반적으로 / ~로 알려져 있다 / ~로 판단된다 / 전문가들에 따르면
```

**결론 위치에서는 허용한다.** 미래에 대해서는 이렇게 쓸 수밖에 없다.

> **F1 즉사(확인 가능한 사실 0개) 시에도 M1은 판정한다.** ☠ 함정 정보를 잃지 않기 위해서다.
> **F2는 즉사가 아니다** — 감점하고 계속 진행한다.

## 3-2. Phase 1.5 — M1 선판정 (AI 잠식)

### ★ M1은 F1·F2 결과와 무관하게 **항상** 판정한다

M1은 **보고서가 아니라 종목의 속성**이다. 보고서가 쓰레기여도 "이 회사는 L2다"는
여전히 참이고, 팀장이 하향 판단에 쓸 수 있는 정보다. **F1에서 죽었다는 이유로
M1을 건너뛰면 ☠ 함정을 놓친다.**

세그먼트 구성은 DART에서 직접 확인하므로 **보고서 품질과 무관하게 판정 가능하다.**

**인과 심사보다도 먼저 한다.** 이유는 두 가지다.

1. **☠ 함정 정보를 잃지 않기 위해.** 위와 같은 이유다.
2. **비용.** M1은 판정 1회로 싸다. 먼저 걸러내면 L1~L2 종목에 비싼 인과 심사
   5종을 돌리지 않아도 된다.

판정 기준은 아래 **§5 M1**과 동일하다. 결과 처리만 여기서 한다.

```
L1~L2  +  M2 산업 성장 ↑   →   ☠ 함정으로 표기 후 탈락 (하향 판단 후보로 팀장에게 전달)
L1~L2  +  M2 산업 성장 →/↓  →   ☠☠ 즉사
L3~L5                      →   Phase 2 인과 심사로 진행
```

L1~L2 판정이 나오면 **M2만 추가로 보고** 인과 심사와 M3·M4는 건너뛴다.

## 4. Phase 2 — 인과 심사 ★ 메인

각 연결 화살표에 5종 공격을 **순서대로** 가한다.

### ① 비약 — 빠진 단계가 있나

```
✕  "AI가 발전한다 → 이 회사 매출이 는다"
   중간이 전부 생략됨. AI 발전이 어떤 경로로 이 회사 고객의
   구매 결정을 바꾸는지가 없다.

○  "AI 발전 → 고객사 설계 인력 감축 → 외주 설계 수요 증가 →
    이 회사 설계 부문 매출 증가"
   각 화살표가 명시됨.
```

2단계 이상 건너뛰면 **끊김 1개.**

### ② 필요≠충분 — 필요조건을 충분조건처럼 썼나

```
✕  "이 회사는 면허를 보유하므로 이익이 늘어난다"
   면허는 이익의 필요조건이지 충분조건이 아니다.
   면허를 가진 경쟁사가 5곳이면 면허는 아무 우위도 아니다.
```

### ③ 역방향 — 같은 전제로 반대 결론도 나오나

**원 보고서가 인용한 문장만 써서 반대 결론을 시도한다.** 새 사실 도입 금지.
반대 결론이 성립하면 그 전제는 아무것도 증명하지 못한다. **끊김 1개.**

```
전제  "매출의 70%가 단일 고객사에서 발생"
UP    안정적 장기 거래 관계 → 실적 가시성
DOWN  고객 집중 리스크 → 교섭력 부재
      → 같은 문장이 양방향. 이 전제는 근거가 아니다.
```

### ④ 제3원인 — 더 유력한 다른 설명이 있나

```
주장  "구조 개선으로 마진이 올랐다"
검사  같은 기간 환율·원자재가·일회성 이익은 어땠나
      환율로 설명되면 구조 개선은 근거가 아니다.
```

### ⑤ 귀속 누락 — 결론이 **주주** 몫인가

`경쟁자 → 고객 → 공급자 → 규제` **네 방향을 차례로** 묻는다.

```
경쟁자   동일 수혜인가 → 가격 경쟁으로 소멸
고객     교섭력 우위인가 → 단가 인하로 이전
공급자   독점인가 → 원가 인상으로 흡수
규제     환수 대상인가 → 요금 인하로 회수
```

### 판정

```
끊긴 고리 2개 이상  →  탈락
끊긴 고리 1개       →  통과, 감점 1
끊긴 고리 0개       →  통과
```

### ★ 끊김은 **고리 단위**로 센다. 공격 단위가 아니다.

```
한 고리(화살표 하나)에 5종 공격 중 3개가 성립해도  →  끊김 1개
서로 다른 두 고리가 각각 하나씩 깨지면            →  끊김 2개
```

**이유**: 우리가 재는 것은 *사슬이 몇 군데 끊겼나*지 *몇 가지 방법으로 때릴 수 있나*가
아니다. 공격 단위로 세면 사슬이 짧은 보고서일수록 유리해지는 역설이 생긴다
(고리가 하나뿐이면 최대 1끊김이지만, 정직하게 5단계로 쪼갠 보고서는 5끊김까지 가능).

**심사표에는 `n끊김 (고리 ②: 필요≠충분·귀속)` 형태로 어느 고리가 왜 깨졌는지 함께 적는다.**
여러 공격이 성립했다는 사실 자체는 그 고리가 얼마나 약한지를 보여주므로 기록한다.

## 5. Phase 3 — 종목 심사 (10~20년 호흡)

### M1 · AI 잠식 — 이 스킬의 핵심

**질문 하나로 끝낸다: "영업이익 1위 세그먼트의 주된 활동이 L몇 단계인가."**

| 단계 | 활동 예시 | AI 도달 | 판정 |
|---|---|---|---|
| **L1** | 번역 · 카피라이팅 · 단순 디자인 · 콜센터 · 데이터 입력 · 기초 리서치 | 이미 도달 | **즉사** |
| **L2** | 회계 장부 · 법률 문서 검토 · 코딩 외주 · 마케팅 기획 · 일반 컨설팅 | 거의 도달 | **즉사** |
| **L3** | 프로젝트 관리 · 영업 · 복잡한 조달 · 다단계 승인 업무 | 진행 중 | 통과 |
| **L4** | 시공 · 설치 · 정비 · 제조 · 물류 현장 · 검사·계측 | 초기 | 통과 |
| **L5** | 인허가 서명 · 감사 의견 · 의료 행위 · 법적 대리 · 안전 책임 | 제도 미해결 | 통과 |

**점수를 매기지 않는다.** L단계는 ① 즉사 여부와 ② 정렬 동점 시 우선순위(L5 > L4 > L3),
③ 분산 규칙(같은 L끼리 중복 배제)에만 쓴다.

- 판정은 **종목당 1회**. 세그먼트가 여러 개여도 **영업이익 1위 하나만** 본다.
- 세그먼트 구분은 DART 사업보고서 "II. 사업의 내용" 부문별 영업이익으로 확인한다.
- 미공시면 매출 구성으로 대체한다.

### ★ L 라벨에도 인용을 요구한다

M1은 **이 스킬에서 유일하게 즉사를 내는 판정**인데, 근거 없이 "주된 활동은 컨설팅"
한 줄 라벨로 끝낼 수 있는 구멍이 있었다. **전제보다 느슨한 즉사 판정은 말이 안 된다.**

```
필수:  세그먼트 영업이익 비중 인용 (DART 문서명·페이지)
       그 세그먼트의 활동을 서술한 원문 인용
없으면:  M1 판정 보류 → L3(중립)로 두고 인과 심사로 진행
```

### ★ L2와 L3의 경계 — 여기서 생사가 갈린다

L4/L5는 둘 다 안전이라 오판이 무해하지만, **L2(즉사)와 L3(생존)의 경계는
생사를 가른다.** 그리고 SI·엔지니어링사가 이 경계에 몰려 있다.

**관찰 가능한 조건으로 판정한다** — 아래 중 **2개 이상 해당하면 L2**:

```
□ 수주·과금 단위가 인월(MM) 또는 투입 인원 기준
□ 판관비 중 인건비 비중이 60% 이상
□ 매출 구성 명칭에 용역 · 컨설팅 · 설계 · 자문 · 위탁 이 들어감
□ 산출물이 문서·도면·데이터로 완결됨 (물리적 인도물 없음)
□ 고객사가 같은 일을 사내에서 할 수 있으나 인력이 없어 외주함
```

마지막 항목이 특히 중요하다. **"인력이 없어서" 외주하는 일은 AI가 인력을 대체하는
순간 사라진다.** 반면 "면허가 없어서" 또는 "설비가 없어서" 외주하는 일은 남는다.

### ★ 한 활동이 여러 단계에 걸칠 때 — 가장 높은 장벽으로 판정한다

활동 하나가 표의 여러 줄에 해당하는 일이 흔하다. 이때는
**"AI가 이 활동을 완전히 대체하려면 넘어야 할 가장 높은 단계"** 로 판정한다.

```
예)  비파괴검사
     영상 판독      → L4 (검사·계측)
     결과 서명 책임  → L5 (안전 책임)

     AI가 판독을 다 해도 서명은 못 한다.
     → 실질 장벽은 L5.  L5로 판정한다.
```

거꾸로, **낮은 단계가 이익의 대부분을 만들면 낮은 쪽으로 판정한다.**

```
예)  설계 + 시공을 함께 하는 회사
     영업이익의 80%가 설계(L2)에서 나온다면 → L2로 판정
     시공(L4)을 한다는 사실이 설계 이익을 지켜주지 않는다.
```

**판정 기준은 "무엇을 하는가"가 아니라 "이익이 어디서 나오고 그것이 대체되는가"다.**

**L단계가 곧 시간축이다.** 그래서 별도 시점 관문을 두지 않는다.

### M2 · 산업 성장 — **점수를 주지 않는다. 매트릭스 축으로만 쓴다.**

향후 10~20년 이 산업의 파이가 커지는가. B의 산업 리서치를 근거로 판정한다.

> **여기는 확정 근거를 요구하지 않는다. 결론 영역이다.**
> B 리서치에 해당 산업이 없으면 보고서 자체 주장을 받아들이되 `근거 C자체`로 표기한다.

```
성장 ↑  /  유지 →  /  축소 ↓        ← 등급만. 점수 없음
```

**★ 점수를 주면 안 되는 이유**: *"이 산업은 앞으로 커진다"* 는 **컨센서스가 이미 아는
정보다.** 여기에 점수를 주면 **컨센과 같은 말을 하는 종목이 보상받는다.**
우리 수익은 컨센과의 차이에서 나오므로, 산업 성장은 **함정을 가려내는 축**으로만 쓴다.

### M1 × M2 — 함정 매트릭스

```
              산업 성장 ↑            산업 성장 ↓
         ┌──────────────────┬──────────────────┐
 L4~L5   │  ★ 편입 1순위     │      중립        │
 (안전)  │  안 죽는데 파이 큼 │                  │
         ├──────────────────┼──────────────────┤
 L1~L2   │  ☠ 함정           │    ☠☠ 즉사      │
 (잠식)  │  파이는 커지는데   │                  │
         │  내 몫이 사라짐    │                  │
         └──────────────────┴──────────────────┘
```

**☠ 함정을 놓치지 마라.** 산업은 성장하는데 그 성장분을 AI가 가져가는 회사다.
시장은 "산업 성장"만 보고 멀티플을 준다.

**함정 종목은 탈락시키되 심사표에 `☠ 함정`으로 표기**한다. 팀장이 **하향 판단 후보**로 쓴다.

### M3 · 이익 귀속 — DART로 증거화

의견이 아니라 **표로 답한다.**

```
주장   "AI 수요 증가로 이 회사 마진이 개선된다"
검사   동종 3사의 최근 8분기 영업이익률을 DART에서 뽑는다
결과   3사 모두 같은 방향·같은 폭으로 움직였다
       → 산업 공통 요인이지 이 회사만의 이익이 아니다  →  M3 = 0
```

"경쟁자도 수혜일 것 같은데요"는 의견이지만 **3사 마진 추이 표는 사실**이고 재현된다.

```
동종 3사 대비 마진 발산 (이 회사만 개선) = 2   /   동조 = 0
```

**비교 3사는 임의로 고르지 않는다.** B의 산업 유니버스에서 **시가총액 인접 3사**를
규칙으로 뽑되, **심사 대상 자신은 반드시 제외한다.** B가 넘긴 목록에 대상 회사가
포함되어 있으면 빼고 다음 순위를 채운다. 자기가 자기 비교군에 들어가면 마진 격차가
자동으로 축소되어 판정이 오염된다.

### 8분기 추이가 없을 때 — 강등 배점

DART 시계열을 못 뽑으면 Phase 2 ⑤(귀속 누락)의 4방향 질문으로 강등하고
**방어한 방향의 수로 채점한다.**

| 방어한 방향 | 점수 |
|---|---|
| 4방향 중 3개 이상 방어 | 2 |
| 2개 방어 | 1 |
| 1개 이하 | 0 |

```
경쟁자   진입장벽·자격 요건 등으로 동일 수혜가 막히는가
고객     교섭력 우위가 없어 단가 인하를 강요당하지 않는가
공급자   독점 공급자에게 원가로 흡수되지 않는가
규제     요금 인하 등으로 환수되지 않는가
```

### ★ 수준 격차와 추이 발산은 다르다

`영업이익률 14.1% vs 동종 9.2%` 는 **단일 시점의 수준 격차**이지 발산이 아니다.
발산은 **격차가 벌어지는 중**이라는 뜻이다.

```
수준 격차만 확인됨      →  최대 1점
격차가 벌어지는 추세    →  2점
```

수준 격차는 "원래 좋은 회사"를 뜻할 뿐, 주장하는 변화가 **이 회사에 귀속된다는
증거가 아니다.** 이 구분을 놓치면 우량주에 자동으로 2점이 붙는다.

### M4 · 상투어 검사

**주가가 아니라 논리로 잰다.** 장기 논리가 12개월 주가에 반영될 리 없으므로
초과수익률 같은 단기 척도는 쓰지 않는다.

이 인과 사슬이 이미 시장의 공통 인식인가.

```
독자적 연결 = 감점 0   /   부분적으로 알려짐 = 감점 1   /   상투어 = 감점 2
```

상투어 예시: *"AI 데이터센터 전력 수요 증가"* · *"온디바이스 AI 수혜"* ·
*"로봇 시장 성장"* — 이미 모두가 아는 연결은 델타가 없다.

### ★ 죽이는 판정에도 근거를 요구한다

이 스킬은 PASS에 근거를 요구하면서 **상투어 판정(감점 2)에는 근거를 안 받는
유일한 구멍**이 있었다. 그러면 어떤 장기 결론이든 "상투어입니다" 한마디로 죽일 수 있고,
§1이 금지한 **결론 공격이 뒷문으로 들어온다.**

```
감점을 매기려면 반드시 답해야 한다:
  "이 연결이 이미 알려져 있다면, 어디에 나와 있는가?"

  → 컨센서스 리포트 제목 / 언론 기사 / 업계 상용구 중 하나를 지목할 것
  → 지목하지 못하면 감점 0 (독자적 연결로 인정)
```

**M4의 최종 형태는 채점이 아니라 증거 제시다.** 컨센 리포트가 이미 그 논리를
쓰고 있다면 우리 델타는 없는 것이고, 그건 표로 보여줄 수 있는 사실이다.

## 6. Phase 4 — 컨센서스 대조 ★ 빼먹으면 프로젝트가 실패한다

**우리 데스크의 수익은 컨센서스와의 차이에서 나온다.**
여기를 건너뛰면 편입 종목이 컨센과 얼마나 다른지를 **아무도 계산한 적이 없게 된다.**

```
컨센 TP     data/consensus.csv 의 consensus_tp
우리 TP     컨센 TP × (1 + 임팩트%)        ← F2에서 검증한 임팩트
델타        우리 TP / 컨센 TP − 1  =  임팩트%
업사이드     우리 TP / 현재가 − 1
```

### 컨센 게이트 (탈락)

```
컨센 커버리지 3곳 미만   →  탈락.  대조 상대가 없으면 판단을 낼 수 없다
|델타| < 20%p           →  탈락.  컨센과 같은 말이면 수익원이 없다
```

**두 번째가 핵심이다.** M점수가 아무리 높아도 컨센과 같은 결론이면 편입할 이유가 없다.
좋은 회사를 찾는 게 아니라 **시장이 틀린 곳**을 찾는 것이다.

컨센 데이터가 아직 없으면 `컨센 미확보` 플래그를 달고 편입하되,
**팀장 단계에서 반드시 채운다.** 채우지 못한 종목은 최종 리포트에 올리지 않는다.

## 7. Phase 5 — 선정

**점수 합산 컷을 쓰지 않는다.** 팀 공통규칙이 21점 채점표를 폐기한 이유가
"등급 채점은 매번 흔들린다"였는데, 여기서 0/1/2 합산 컷을 부활시키면 같은 문제가 돌아온다.
**즉사 게이트와 정렬만 쓴다.**

### 즉사 게이트

```
F1     확인 가능한 [사실]이 0개
M1     L1~L2                     (산업 성장 시 ☠ 함정 표기 후 탈락)
인과    끊긴 고리 2개 이상
M3     귀속 방어 실패 (0점)        이익이 주주에게 안 남으면 살릴 이유가 없다
컨센    커버리지 3곳 미만
델타    |델타| < 20%p             (임팩트가 유효할 때만 적용. 규모 미기재는 이 게이트를 건너뛴다)
```

**F2는 즉사 게이트가 아니다.** 규모가 없으면 감점하고 최하위로 밀 뿐 죽이지 않는다.

### 정렬 — 2계층

```
승률     = 0.55 − 0.10 × (인과 끊김 + M4 감점 + 규모 미산출)
기대수익 = 업사이드 × 승률
```

**팀 보고서에는 규모가 없는 경우가 흔하다.** 전원이 미산출이면 기대수익이
전부 비어 정렬이 무너진다. 그래서 두 계층으로 나눈다.

```
[1계층]  임팩트가 산출된 종목        기대수익 내림차순
            └ 동점이면 M1 단계가 높은 쪽 (L5 > L4 > L3)

[2계층]  임팩트 미산출 종목          1계층 전부 아래에 배치
            └ 인과 끊김 적은 순  →  M1 단계 높은 순
```

**1계층이 항상 2계층보다 위다.** 크기를 댄 주장이 크기를 안 댄 주장을 이긴다.
PB 데스크는 결국 금액으로 답해야 하기 때문이다.

2계층 종목이 편입되면 **`규모 산출 필요` 플래그와 보강 지시를 팀장에게 함께 넘긴다.**

**점수 순이 아니라 돈 순이다.** 9점짜리 +5% 종목이 8점짜리 +40% 종목을 이기면
PB 데스크가 아니다.

### 분산

```
L단계가 이미 담은 종목과 같으면 건너뛴다
셋 다 L4면 물리 자동화가 진전될 때 동시에 무너진다
```

### 선정

최대 3개. **미달이면 미달인 채로 제출한다.**

## 8. 출력

### ① 심사표 — 항상 발행

**열 순서는 심사 순서와 같다: F1 F2 → M1 → 인과 → M2 M3 M4 → 컨센 대조**

```
종목   F1 F2  M1     인과   M2 M3 M4  임팩트  컨센TP  우리TP   델타   승률  기대수익  판정     탈락사유
────────────────────────────────────────────────────────────────────────────────────────────────────
○○○   ✓  ✓  L4    0끊김   ↑  2  0   +24%   32,000  39,680  +24%  0.55   +38.5%  편입 1위  -
□□□   ✓  ✓  L5    1끊김   ↑  2  1   +30%   18,000  23,400  +30%  0.35   +21.0%  편입 2위  -
△△△   ✓  ✓  L4    2끊김   -  -  -     -       -       -      -     -       -    반려     비약·제3원인
◇◇◇   ✕  -   -      -     -  -  -     -       -       -      -     -       -    반려     확인 가능한 사실 0개
☆☆☆   ✓  ✓  L2     -      ↑  -  -     -       -       -      -     -       -    ☠ 함정   산업↑ 이나 L2 잠식
◎◎◎   ✓  ✓  L4    0끊김   ↑  2  0   +12%   25,000  28,000  +12%    -       -    반려     델타 12%p < 20%p
```

- **M2는 등급(↑ → ↓)만.** 점수를 주지 않는다 — 컨센이 이미 아는 정보이기 때문
- **M3** 2/1/0, **M4**는 감점(0/1/2)
- **승률** = 0.55 − 0.10 × (인과 끊김 + M4 감점 + 규모 미기재)
- **기대수익** = 업사이드 × 승률. **정렬은 이것으로 한다** (점수 합산 컷 없음)
- 마지막 행 `◎◎◎` 는 **모든 관문을 통과하고도 델타가 작아 반려**되는 경우다.
  좋은 회사를 찾는 게 아니라 **시장이 틀린 곳**을 찾는 것이므로 이게 정상이다
- `-` 는 앞 관문에서 탈락해 판정하지 않은 것.
  **불필요한 판정을 하지 않는 것도 규칙이다.**

이 표가 데스크가 작동한다는 물증이다. 팀장이 최종 리포트에 그대로 붙인다.
